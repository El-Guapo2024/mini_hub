# Exponents/Powers (Evaluation)

The three rules that answer almost every question here:

$$
x^a\cdot x^b = x^{a+b} \qquad \frac{x^a}{x^b} = x^{a-b} \qquad (x^a)^b = x^{ab}
$$

**Product rule:** if $3^x = 70.1$, then $3^{x+2} = 3^x\cdot 3^2 = 70.1\cdot 9 = \mathbf{630.9}$.

**Quotient rule:** if $5^x = 2$, then $5^{x-2} = \dfrac{5^x}{5^2} = \dfrac{2}{25} = \mathbf{0.08}$.

**Power rule:** if $4^x = 1.1$, find $2^{6x}$. Since $4^x = (2^2)^x = 2^{2x} = 1.1$, we get $2^{6x} = (2^{2x})^3 = 1.1^3 = \mathbf{1.331}$.

You'll also see mixed-base problems like $6^{2x}=36$, then $6^{3x}=?$ Since $(6^x)^2=36$, $6^x=6$, so $x=1$ and $6^{3x}=6^3=\mathbf{216}$. And radical/fractional-exponent combinations, e.g. $\sqrt[3]{a^4}\times\sqrt[4]{a^3} = a^{4/3}\cdot a^{3/4} = a^{25/12} = \sqrt[12]{a^{25}}$, so $n=\mathbf{25}$.

Since a logarithm is just the inverse question ("what exponent?"), this topic also includes problems phrased with logs. Use the definition $\log_a b = x \iff a^x = b$ directly: if $\log_x 64 = 1.5$, then $x^{1.5}=64$, so $x = 64^{2/3} = \mathbf{16}\text{;}$ if $3\log_2 x = 6$, then $\log_2 x = 2$, so $x=4$ and $\sqrt{x}=\mathbf{2}$.

Finally, "remainder" questions ask you to evaluate both sides as ordinary integers and divide: $2^8 \div 4^3 = 256 \div 64 = 4$ remainder $\mathbf{0}$.

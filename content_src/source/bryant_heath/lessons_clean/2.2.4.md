# Number of Diagonals of a Polygon

The formula for the number of diagonals in a polygon is derived by noticing that from each of the $n$ vertices in an $n\text{-gon}$, you can draw $(n-3)$ diagonals creating $n \cdot (n-3)$ diagonals, however each diagonal would be drawn twice, so the total number of diagonals is:

$$
\text{\# of Diagonals} = \frac{n \cdot (n-3)}{2}
$$

As an example, the number of diagonals in a hexagon is:

$$
\text{\# of Diagonals in a Hexagon} = \frac{6 \cdot 3}{2} = 9
$$

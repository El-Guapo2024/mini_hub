# Identity: n² + n = (n+1)² − (n+1)

This section addresses a type of problem that appears on recent Number Sense tests. By restating $n^2 + n$ in a different way, the same factoring leads to an easier computation:

$$
n^2 + n = n^2 + 2n + 1 - n - 1 = (n+1)^2 - (n+1)
$$

Use this identity when you see $n^2 + n$ and $n$ is one away from a multiple of 10 or 5, making the squaring and subtraction easy:

$$
89^2 + 89 = 90^2 - 90 = 8100 - 90 = \mathbf{8010}
$$

The trick also works in reverse — rewrite $(n+1)^2 - (n+1)$ as $n^2 + n$:

$$
66^2 - 66 = 65^2 + 65 = 4225 + 65 = \mathbf{4290}
$$
